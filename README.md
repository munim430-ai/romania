## 🏛️ Institutional Overview

**Keystone Global Workforce Solutions** is the specialized technical recruitment division of **Keystone Education Consultancy** ([www.keystoneeducations.com](https://www.keystoneeducations.com)), headquartered in Rajendrapur Bazar, Gazipur, Dhaka Division, Bangladesh.

We bridge the severe skilled labor shortage across Romania's construction, logistics, manufacturing, and hospitality sectors by providing vetted craftsmen certified through Bangladesh Government Technical Training Centers (TTCs), complete with end-to-end legal document preparation.

## 🌟 Key Features & Capabilities

1. **Bilingual Engine (English 🇬🇧 & Romanian 🇷🇴):** Instant real-time UI localization for Romanian HR directors, recruiters, and immigration lawyers.
2. **Interactive 7-Step Document Preparation Hub:**
   - **Step 1:** 10-Year e-Passport & Biometric Screening.
   - **Step 2:** Clean Police Clearance with Ministry of Foreign Affairs (MOFA) Legalization & QR stamp.
   - **Step 3:** Fit-to-Work Medical Clearance (Chest X-ray, Hep B/C, HIV, VDRL, drug screen).
   - **Step 4:** COR-Aligned Europass CV.
   - **Step 5:** 4K Practical Trade Skill Test Video + QR stamping on CV for one-click audition review.
   - **Step 6:** Single Permit Dossier (Ready for instant IGI upload).
   - **Step 7:** BMET Smart Card Emigration Clearance.
3. **Live Candidate Showroom:**
   - Pre-screened candidates (MIG/MAG Welders, Steel Fixers, Electricians, Forklift Operators, Chefs, CNC Machinists).
   - Simulated 4K Video Audition player with trade test metric scorecards.
4. **Official Romanian Deficit Occupations Explorer (COR):**
   - Direct integration with official shortage occupational codes from `workinromania.gov.ro`.
   - Real-time search, industry filtering, and gross salary benchmarks in RON/EUR.
5. **B2B Quota & Timeline Calculator:**
   - Dynamic lead time calculator broken down by milestone (Shortlist -> MOFA -> IGI Permit -> Consular Visa -> Flight).
6. **RAPS Agency Client Portal Placeholder & Interactive Simulator:**
   - Multi-tabbed agency dashboard demonstrating live candidate tracking, batch IGI zip downloads, and demand orders.
7. **Institutional Guarantee:**
   - 90-Day Free Replacement Warranty.
   - Zero upfront sourcing fee for accredited Romanian agencies.

## 🚀 Instant Vercel Deployment Guide

This project is built with zero runtime dependencies (HTML5, modern modular CSS, and vanilla ESNext JavaScript), ensuring instant builds and lightning-fast edge performance.

### Option A: Manual Deployment via Vercel CLI

```bash
# 1. Install Vercel CLI (if not already installed)
npm install -g vercel

# 2. Deploy directly from the project directory
vercel --prod
```

### Option B: Deploy via Vercel Dashboard (GitHub Integration)

1. Go to [vercel.com/new](https://vercel.com/new).
2. Import the GitHub repository: `https://github.com/munim430-ai/romania`.
3. Keep default settings:
   - **Framework Preset:** `Other`
   - **Root Directory:** `./`
   - **Build Command:** *(Leave empty)*
   - **Output Directory:** `./`
4. Click **Deploy**. Your site will be live within 10 seconds.
